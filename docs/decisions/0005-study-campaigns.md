# Decision 0005: bounded campaigns and frozen confirmation

Frozen before campaign/calibration implementation, September 8, 2026. Inputs remain manufactured controls. No campaign probability, fitted parameter or confirmation result becomes environmental validation.

A sensitivity campaign freezes its base study, ordered explicit parameter samples, units/path bindings, dependence description and attempt/time budgets before execution. Every sample is retained as succeeded, invalid, failed or not run because a budget was exhausted. Invalid outcomes never enter a valid ranking, but remain in denominators. Each completed sample is an ordinary independently evaluated portable network bundle. Results report all paired arm metrics and whether ordering reverses across sampled conditions. This is a tested region, not a probability distribution or a global optimum.

A resolution control uses a declared one-dimensional normalized channel with fixed total volume, prescribed flow, initial uniform conservative mass, clean inlet and no source or conversion. Equal-volume cells form a donor-cell compartment chain. The continuous plug-flow control retains `M0 * max(1 - Q*t/V, 0)` kg. Cell counts 1, 2, 4 and 8 share the boundary/support and total initial quantity. Each discrete solution also has an independent exponential reference, separating time-integration error from spatial/model approximation. Spatial convergence is never inferred from changing an arbitrary network topology. Conservative overlap remapping checks identical domain support and reports mass residual separately from profile reconstruction error.

Calibration freezes development and holdout study identities, synthetic observations with units/support, parameter candidates, loss, equivalence tolerance, validation threshold and resource budget. Candidate fitting sees only development data. It retains every attempt and computes a sum of squared residuals in kg². Multiple candidate parameter vectors within the frozen equivalence tolerance are reported as unresolved on the tested grid; a single selected vector does not establish global identifiability.

Opening holdout observations writes a durable access event before evaluation. Confirmation uses the frozen selected parameters and unchanged thresholds and retains every failed case. Further fitting against the same frozen cohort after holdout access is refused. A revision that uses those outcomes must explicitly consume the holdout into development evidence and freeze a new cohort. Reproduction of a frozen selection is distinct from a fresh independent holdout test. Hashes detect changed stored bytes; they do not establish authenticity against an author who controls all files.

All evidence directories are fresh. Final completion markers mean the campaign protocol finished, not that every case is scientifically valid. Interruption leaves each completed child bundle intact and identifies unfinished work; there is no automatic duplicate rerun. Inspect verifies children and recomputes summaries without invoking either solver. A matched source package is required to reproduce. No additional process workers, external solver, model invocation, dependency, dataset or paid service is adopted.
