## Participant workflow

Use the exact versioned source artifact and its checksum manifest. Record whether it was obtained publicly without developer credentials. Use Python 3.12 in the environment being claimed, with no source-checkout dependency or production-library installation.

1. Run `earth.py catchment run --out runs/first`, inspect it and open the offline report. Locate compartment, escaped, stored and unknown-fate quantities. Explain why capture is not safe-disposal evidence.
2. Change source factor or capture capacity in a fresh run. Verify the trajectory changes and the parent study identity is retained.
3. Run a custody negative control. Record the expected rejection and its reason.
4. Run the default sensitivity campaign. Locate its invalid sample and identify the prevention/capture ordering reversal.
5. Run the resolution control. Distinguish time, spatial and total error; compare mass conservation with remap profile error.
6. Freeze the default synthetic cohort, fit and confirm. Locate equivalent candidates and the intentionally invalid candidate. Confirm that fitting again after exposure is refused.
7. Export and reopen confirmation evidence. Reproduce it with the matching source and identify the frozen-selection replay label. It must not claim a fresh holdout test.
8. Interrupt a new operation before completion. Preserve its partial evidence and recover into a fresh directory; if holdout was already exposed, retain exposure and use explicit replay.
